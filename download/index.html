Pouf Helper for Mac

A small menu-bar app that lets Pouf on your iPhone control your Mac. Install it once and it waits quietly in the menu bar.

Install it

  1. Open the disk image

    Open Pouf-Helper-1.0.dmg from your Downloads folder.

  2. Drag it to Applications

    In the window that opens, drag Pouf Helper onto the Applications folder. If an older copy is running, quit it from its menu first.

  3. Open Pouf Helper

    Open it from Applications. A Pouf icon appears in the menu bar at the top of the screen. The helper has no Dock icon.

  4. Allow Local Network

    When macOS asks, click Allow, so your iPhone can find this Mac.

  5. Grant Accessibility

    Click Grant Access in the Pouf menu, then turn on Pouf Helper in System Settings › Privacy & Security › Accessibility. The helper needs this to move the pointer and press keys.

  6. Pair your iPhone

    Choose Pair iPhone… in the Pouf menu and scan the code with Pouf on your iPhone. The code is valid for 2 minutes and works once.

Good to know

Why isn't it on the Mac App Store?

The helper needs Accessibility permission and runs outside the App Sandbox, so it comes as a download from this site instead. It is signed with an Apple Developer ID and notarized by Apple, which means Apple checked it for malicious software before you open it.

Checking the download

Pouf Helper is signed with an Apple Developer ID whose Team ID is K768X7CB7V. To check a downloaded copy before you open it, run this in Terminal:

spctl -a -vv -t open --context context:primary-signature ~/Downloads/Pouf-Helper-1.0.dmg

The answer should say accepted and Notarized Developer ID, and its last line should end with (K768X7CB7V). If it shows another Team ID or anything else, don't open the file, and let us know.

To compare the SHA-256 above, run shasum -a 256 ~/Downloads/Pouf-Helper-1.0.dmg.

Updating

Quit Pouf Helper from its menu, download the new version and drag it to Applications again, replacing the old copy.

Uninstalling

Remove your iPhones under Devices in the Pouf menu, quit the helper and move it from Applications to the Trash. You can also remove it from the list in System Settings › Privacy & Security › Accessibility.
